# 🛍️ ShopEase – B2C E-Commerce Website

ShopEase is a modern and responsive **B2C e-commerce website** built using **HTML, CSS, and JavaScript**. It provides users with a simple and interactive online shopping experience.

## 🚀 Features

* 🏠 Responsive homepage
* 🛍️ Product listing
* 🔎 Product search
* 🏷️ Category filtering
* 🛒 Add to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 💰 Automatic cart total calculation
* 🌙 Dark mode
* 🔔 Add-to-cart notifications
* 📧 Newsletter subscription
* 📱 Mobile responsive design

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and cart functionality

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start exploring ShopEase.

No server or installation is required.

## 🛒 Main Functionality

Users can:

* Browse products
* Search for products
* Filter products by category
* Add products to the shopping cart
* Change product quantities
* Remove products
* View the total price
* Switch between light and dark mode
